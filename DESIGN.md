## Visión general

Portada de GitHub para personas que quieren crear un juego con GameMaker y su asistente
de IA. El encargo pide una presentación moderna, visual y comprensible al primer vistazo,
con instalación fácil y acceso al conocimiento profundo. La dirección es una guía de
campo de desarrollo: páginas abiertas que se convierten en pequeños mundos de juego.

ENERGY 3: una ilustración original hace visible el propósito creativo. RHYTHM 2: portada,
comando de instalación, diagrama y enlaces tienen composiciones distintas. MOTION 1:
imágenes estáticas; ninguna animación necesaria para leer o navegar.

La ilustración representa el método y se identifica como tal. No es una captura de un
juego entregado ni una demostración de calidad AAA. El contenido técnico y las pruebas
de la biblioteca aportan la evidencia real.

## Colores

Verde tinta para lectura, verde salvia para materiales del taller y terracota para el
acento de creación. Papel cálido vincula el conocimiento a una biblioteca. Los neutros
dominan para que la ilustración no compita con los comandos. El texto se conserva sobre
fondos sólidos. GitHub controla los colores, enlaces y temas del Markdown.

## Tipografía

Las imágenes usan títulos serif de alto contraste, con formas editoriales grandes.
No se identifica una fuente exacta en el raster generado. GitHub conserva su
tipografía de sistema en el texto accesible; monospace se limita a comandos reales.
Los títulos de imagen se repiten como texto o mediante alternativa equivalente.

## Composición

El primer bloque responde qué instalar y para qué sirve. Una única imagen de portada,
un comando de inicio y enlaces breves preceden al detalle. El diagrama presenta el ciclo
real de especificación, tareas, construcción y verificación, con retorno al diagnóstico.
Las guías extensas se enlazan. Las imágenes son fluidas; las tablas anchas se evitan.

## Profundidad

Profundidad ilustrada en los mundos de papel para representar sistemas conectados.
El README usa jerarquía de títulos y espacio en blanco; no simula ventanas ni controles.

## Formas

Páginas, fichas de especificación y piezas de juego como motivo repetido. Bordes rectos
y pequeñas esquinas suaves mantienen la relación con herramientas de creación.

## Componentes

Portada, gráfico del método y tarjeta social comparten paleta y motivo. Los enlaces tienen
destinos comprobados. El texto esencial sigue disponible si no se carga una imagen.
El README explica qué hacer si falta GameMaker o un harness compatible, y enlaza el
diagnóstico de instalación. La imagen social conserva título y lectura en miniatura.

Los tres iconos vectoriales propios representan páginas, una ficha comprobada y búsqueda
entre fichas. Comparten geometría de 64 unidades y papel cálido; se muestran a 32 píxeles.
Son decorativos junto a títulos legibles, con alternativa vacía. No son controles ni
logotipos de los harnesses y conservan lectura sobre los temas claro y oscuro de GitHub.

La guía visual amplía tres relaciones que la portada no explica: conocimiento → método →
proyecto, especificación → tareas → pruebas y búsqueda semántica → contexto seleccionado.
Cada ilustración tiene una composición propia, pocas etiquetas grandes y una explicación
equivalente en Markdown. El README muestra la primera y enlaza la guía completa para
conservar una entrada breve. Las flechas representan relaciones reales del procedimiento;
ninguna cifra de ahorro ni estado de verificación se inventa dentro de una imagen.

## Criterios de entrega

- Presentar instrucciones de instalación ejecutadas y compatibilidad con alcance declarado.
- Mantener contraste AA: 4,5:1 en texto normal y 3:1 en texto grande.
- Comprobar el README renderizado en GitHub claro y oscuro, móvil y escritorio.
- Identificar ilustraciones conceptuales y separar pruebas documentales de aceptación de juegos.
- Conservar el modelo elegido; la herramienta integrada no permite verificar su identificador interno.
- Usar imágenes originales sin identidades personales, material privado, logotipos ajenos ni IP comercial.
- Evitar métricas inventadas, promesas automáticas de AAA, testimonios y controles decorativos.
