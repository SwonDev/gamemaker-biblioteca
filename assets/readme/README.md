# Ilustraciones de la portada

Tres ilustraciones originales generadas el 11-10-2026 mediante la herramienta integrada
`imagegen` de Codex, por petición del autor. Modelo solicitado: **GPT Image 2.5**.
La herramienta no devuelve el identificador interno del modelo; no se certifica una
variante API a partir del resultado.

| Archivo | Uso | Formato y dimensiones |
|---|---|---|
| `portada.webp` | Portada del README | WebP · 1774 × 887 |
| `ciclo.webp` | Ciclo de desarrollo | WebP · 1254 × 1254 |
| `vista-social.jpg` | Vista social de GitHub | JPEG · 1280 × 640 · menos de 1 MB |

**Dirección:** un libro de campo se transforma en mundos originales de plataformas,
aventura y puzles. Papel cálido, verde tinta, salvia y terracota. Tipografía editorial
grande, composición asimétrica y motivos propios. Son ilustraciones conceptuales,
no capturas de un juego ni resultados de pruebas.

**Prompts de producción:**

- Portada: ilustración editorial horizontal 2:1, libro abierto que se convierte en tres
  pequeños mundos; texto exacto «GameMaker» y «Biblioteca + skill»; personajes originales,
  contraste alto y espacio suficiente para leer en móvil.
- Método: diagrama cuadrado de cuatro páginas, con flechas en sentido horario y etiquetas
  exactas «Especifica», «Construye», «Comprueba» y «Mejora»; fichas, piezas y lupa muestran
  el ciclo, con la misma paleta.
- Vista social: variante de la portada, usando esa imagen como referencia; composición 2:1
  legible en miniatura; texto exacto «GameMaker», «Tu IA. Un método para crear juegos.»
  y «Biblioteca + skill».

Restricciones comunes: sin personajes de obras existentes, logos ajenos, datos personales,
material privado, métricas inventadas, interfaces falsas, robots, neón ni marcas de agua.
Son imágenes raster; no se produjo un modelo 3D.

Los PNG originales se conservan fuera del repositorio. Las copias publicadas se comprimieron
con WebP calidad 85; la social se redujo a 1280 × 640 y JPEG calidad 91. Se retiraron metadatos.
